# JOYA'S MESS

Mess and tiffin management app (React + Vite + Tailwind). Currently runs on in-memory sample data; changes reset on refresh. Supabase is not connected yet.

## Run
1. Install Node.js 18 or newer from https://nodejs.org
2. In this folder run `npm install`
3. Run `npm run dev` and open the address it prints (usually http://localhost:5173)

Build for hosting: `npm run build` (output in `dist`).
